# 🌿 GhibliArchive 🌿

**GhibliArchive** é um aplicativo iOS dedicado a estudos em Combine e a explorar os filmes do Studio Ghibli. O app permite aos usuários navegar pelo catálogo completo de filmes, marcar seus filmes favoritos e obter informações detalhadas sobre cada obra-prima animada.

---

## 🚀 Funcionalidades

- **Exploração de Filmes**: Navegue por uma lista completa de filmes do Studio Ghibli.
- **Detalhes do Filme**: Acesse informações detalhadas sobre cada filme, incluindo título, descrição e imagem.
- **Favoritos**: Marque seus filmes favoritos e salve-os para fácil acesso.
- **Busca**: Encontre filmes rapidamente com uma busca simples.

## 🌈 Tecnologias Utilizadas

- **Swift**: Linguagem de programação principal.
- **UIKit**: Framework de interface gráfica.
- **Combine**: Para gerenciar fluxo de dados reativos.
- **UICollectionViewDiffableDataSource**: Para gerenciamento dinâmico e eficiente de dados em coleções.

---

## 🏰 Estrutura do Projeto

- **MVVM (Model-View-ViewModel)**: Para separar claramente a lógica de negócios da interface do usuário.
- **Clean Architecture**: Para garantir que o código seja modular, testável e fácil de manter.
